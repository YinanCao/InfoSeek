**Instructions on generating CSV data for the COLEXP online task** 

1. To create a new batch of data, first make sure that there is no file unique_id_list.mat in the working directory.

2. Open gen_online_task.m. Make sure that the name of the table is 'data'. 

3. Set the variable 'datafile' to the filename inside /tables/.

4. Run the script.

5. The CSV files are stored in /data/
